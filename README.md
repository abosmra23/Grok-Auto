 🎨 Grok Bulk Imagine

**Grok Bulk Imagine** is a powerful automation tool and SaaS platform designed to streamline bulk image generation on **Grok**. It features a Chrome Extension for automation and a full Vercel-hosted dashboard for user management and subscriptions.

---

## ✨ Key Features

### 🧩 Chrome Extension
- **Bulk Text-to-Image**: Queue hundreds of prompts and let the tool generate them automatically.
- **Image-to-Image Automation**: Upload reference images and apply prompts in bulk.
- **Smart Queue System**: Handles errors, retries failed generations, and manages delays to avoid rate limits.
- **Auto-Save**: Automatically downloads generated images and takes screenshots of the process.
- **Premium UI**:  A beautiful, dark-themed interface with drag-and-drop support and real-time progress tracking.

### 🌐 SaaS Platform (Web Dashboard)
- **User Authentication**: Secure login and signup system using **Supabase**.
- **Subscription Management**: Integrated **PayPal** gateway for handling Pro subscriptions.
- **Live Sync**: Real-time checking of subscription status directly from the extension.
- **Responsive Design**: Modern, animated UI built with vanilla CSS/JS for maximum performance.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla JavaScript, CSS3 (Glassmorphism & Animations)
- **Backend & Auth**: Supabase (PostgreSQL, Auth)
- **Hosting**: Vercel (Clean URLs enabled)
- **Payments**: PayPal JavaScript SDK
- **Extension**: Chrome Manifest V3
